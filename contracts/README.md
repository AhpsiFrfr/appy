# Smart Contracts

This directory will contain Solidity contracts for the gig marketplace. Planned contracts include:

- `GigEscrow.sol` – Handles gig creation, escrow of payments, and release to freelancers.
- `TokenVesting.sol` – Manages vesting schedules for future token allocations.
- `EquityToken.sol` – ERC-1155 token representing fractional equity or performance bonuses.

`GigEscrow.sol` is implemented with support for ETH and ERC-20 payments, a 10% platform fee, and basic dispute tracking. Other contracts remain TODO.
